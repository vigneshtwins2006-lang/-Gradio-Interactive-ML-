# Task 5 Submission – Streamlit Interactive ML Web App

**Project name:** House Price Predictor – Interactive ML Web App (Streamlit)

**GitHub repo name:** `house-price-streamlit-app`

**Short description:**
An interactive Streamlit web app that loads a trained Scikit-Learn model (via joblib) and predicts house prices in real time from input sliders.

**Full description:**
This project deploys the Task 4 models as a web app. A Linear Regression model predicts the price of a house, and a Decision Tree Classifier labels it as High or Low priced with a confidence score. Users change the input features with sidebar sliders and the prediction updates instantly. The app also shows model performance (R², RMSE, MSE, Accuracy) and feature importance charts.

**Key features:**
- Streamlit interface creation
- Model loading with joblib (cached with st.cache_resource)
- Interactive, real-time prediction display

**Tech stack:** Python, Pandas, Scikit-Learn, Joblib, Streamlit
